# SpeedRead

Тренажер швидкочитання в браузері: слова з'являються по одному в тому самому місці, опорна літера підсвічена червоним під рискою — очам не треба стрибати рядком.

Відкрити: https://genichka.github.io/SpeedRead/

## Тест «На якій швидкості ти зламаєшся?»
- Швидкість росте сходинками: 250 → 300 → 375 → 450 → 550 → 700 → 900 слів/хв.
- Щойно перестаєш розуміти — **«Зламався»** (або пробіл). Записується межа, а текст іде далі на сходинку повільніше; ще одне натискання — ще повільніше.
- Наприкінці 3 запитання на розуміння. Результат: комфортна швидкість, межа, розуміння й ефективна швидкість (з урахуванням розуміння).
- Тексти українською та англійською, щоразу новий, поки не пройдеш усі.

## Читання
- Будь-який текст з бібліотеки або свій: вставити або відкрити файл `.txt` (UTF-8 чи Windows-1251).
- Швидкість 100–1500 слів/хв, 1–3 слова за раз, паузи на розділових знаках і довгих словах (середня швидкість при цьому не змінюється), розгін до цілі.
- Пауза — дотиком до вікна читання; у паузі видно контекст абзацу, дотик до слова переносить до нього. «Попереднє / наступне речення».
- Позиція в кожному тексті запам'ятовується. Після бібліотечного тексту — перевірка розуміння.
- Клавіатура: пробіл — старт/пауза, ← → — речення, ↑ ↓ — швидкість.

## Таблиці Шульте
3×3 … 7×7, червона крапка в центрі для фіксації погляду, лічильник помилок, рекорд для кожного розміру, режим з перемішуванням після кожного числа.

## Прогрес
Найкраща комфортна швидкість (з розумінням від 2/3), найвища межа, прочитані слова й час, графік тестів, історія, рекорди Шульте.

## Встановлення на телефон
Відкрий сайт у Chrome → меню ⋮ → «Встановити застосунок». SpeedRead з'явиться з власною іконкою і працюватиме без інтернету.

## Версія й оновлення
Номер версії й дата — у шапці, поруч кнопка «Оновити». Вона порівнює версію з `version.json` на сайті й ставить нову лише після підтвердження, з коротким описом змін.

## Збирання
Код лежить у `src/`. Скрипт `build.sh` збирає з частин `index.html` і генерує `version.json` з `src/00_version.js`. Для нової версії зміни номер, дату й список змін у `src/00_version.js`.
