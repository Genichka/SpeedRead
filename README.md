# SpeedRead

Тренажер швидкочитання в браузері: слова з'являються по одному в тому самому місці, опорна літера підсвічена червоним під рискою — очам не треба стрибати рядком.

Відкрити: https://genichka.github.io/SpeedRead/

## Тест «На якій швидкості ти зламаєшся?»
- Швидкість росте сходинками: 250 → 300 → 375 → 450 → 550 → 700 → 900 слів/хв.
- Щойно перестаєш розуміти — **«Зламався»** (або пробіл). Записується межа, а текст іде далі на сходинку повільніше; ще одне натискання — ще повільніше.
- Наприкінці 3 запитання на розуміння. Результат: комфортна швидкість, межа, розуміння й ефективна швидкість (з урахуванням розуміння).
- Тексти українською та англійською, щоразу новий, поки не пройдеш усі.

## Читання
- Будь-який текст з бібліотеки або свій: вставити або відкрити файл `.txt` (UTF-8 чи Windows-1251).
- Швидкість 100–1500 слів/хв, 1–3 слова за раз, паузи на розділових знаках і довгих словах (середня швидкість при цьому не змінюється), розгін до цілі.
- Пауза — дотиком до вікна читання; у паузі видно контекст абзацу, дотик до слова переносить до нього. «Попереднє / наступне речення».
- Позиція в кожному тексті запам'ятовується. Після бібліотечного тексту — перевірка розуміння.
- Клавіатура: пробіл — старт/пауза, ← → — речення, ↑ ↓ — швидкість.

## Англійські слова й WordHunter
- У «Читанні» є англійські тексти рівнів [WordHunter](https://genichka.github.io/trainer/): A1–B2, технічні та 15 книжок.
- У паузі торкнись англійського слова: переклад зі словника WordHunter і рівень слова (форми на кшталт walks, children, went зводяться до walk, child, go).
- «Вчити у WordHunter» кладе слово в список «Слова для WordHunter». Кнопка «Відкрити у WordHunter» відкриває гру посиланням `#sr-add=…`, і ці слова отримують позначку «важко»: ідуть першими в уроках свого рівня й потрапляють у «Роботу над помилками».
- Словник і тексти беруться з репозиторію WordHunter: `python3 tools/make_dict.py <шлях до trainer>` генерує `src/01_dict.js`, потім `./build.sh`.

## Таблиці Шульте
3×3 … 7×7, червона крапка в центрі для фіксації погляду, лічильник помилок, рекорд для кожного розміру, режим з перемішуванням після кожного числа.

## Прогрес
Найкраща комфортна швидкість (з розумінням від 2/3), найвища межа, прочитані слова й час, графік тестів, історія, рекорди Шульте.

## Android-додаток (APK)
Завантажити: https://github.com/Genichka/SpeedRead/releases/download/apk-latest/SpeedRead.apk (сторінка — [Releases](https://github.com/Genichka/SpeedRead/releases/tag/apk-latest)).

Відкрий файл на телефоні й дозволь встановлення з цього джерела. Додаток працює без інтернету, екран не гасне під час читання й тесту, а «Поділитися» виділеним текстом з будь-якого застосунку відкриває його в SpeedRead.

APK збирає GitHub Actions (`.github/workflows/android.yml`) при кожному оновленні `main` і викладає в Releases з тегом `apk-latest`. Android-проєкт — тека `android/`: WebView з файлами застосунку всередині APK. Пароль ключа підпису — секрет `SR_KEY_PASS` у Settings → Secrets and variables → Actions. Сам ключ `android/app/speedread.keystore` збірка створює першого разу й шифрує цим паролем; у коді пароля немає.

## Версія й оновлення
Номер версії й дата — у шапці, поруч кнопка «Оновити». Вона порівнює версію з `version.json` на сайті й лише після підтвердження, з коротким описом змін, ставить нову: на сайті — одразу, у додатку — завантажує новий APK, який встановлюється поверх старого (прогрес, рекорди й тексти зберігаються).

Сайт теж можна встановити як застосунок: Chrome → меню ⋮ → «Встановити застосунок».

## Збирання
Код лежить у `src/`. Скрипт `build.sh` збирає з частин `index.html` і генерує `version.json` з `src/00_version.js`. Для нової версії зміни номер, дату й список змін у `src/00_version.js`.
